# Azure-ServiceDesk-Automation

This repository is a collection of demonstrations, scripts, presentations, and
workshop materials shared at community events. Its goal is to help people learn
about the topics presented and reproduce the demonstrations in their own
environments.

Materials may cover:

- Community meetups and Microsoft community activities
- Azure networking sessions
- GitHub Copilot workshops
- AI and cloud events

## Learning and reproducing demonstrations

Start with the README or instructions provided alongside each resource. Check
its prerequisites and required permissions, and review scripts before running
them. Demonstrations that create or change cloud resources may incur charges;
use an appropriately scoped subscription and clean up resources afterward.

Adapt configuration and credentials for your own environment. Do not commit
secrets, access tokens, or other sensitive information.
